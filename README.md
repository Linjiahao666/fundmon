# 基金盘中估值飞书提醒

用基金季报前十大持仓加权 A 股实时涨跌，估算盘中净值变化，并按自定义规则推到飞书私聊。

通知关闭时不会请求行情。周末、法定节假日、午休和收盘后到期的规则会跳过，不补发。

## 服务器一键安装

在 Linux 交互式终端执行：

```bash
curl -fsSL https://raw.githubusercontent.com/Linjiahao666/fundmon/main/install.sh | bash
```

脚本会引导你选择安装目录、拉取仓库、安装 Python 依赖、填写飞书凭证，并注册为开机自启服务。需要本机已能访问 GitHub，以及 Python 3.11 或更高版本。

## 准备

- Python 3.11 及以上
- 飞书企业自建应用，并开通机器人

本机手动安装：

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e .
copy .env.example .env
```

在 `.env` 中填写 `FEISHU_APP_ID` 与 `FEISHU_APP_SECRET`。

## 飞书应用配置

1. 打开 [飞书开放平台](https://open.feishu.cn/)，创建企业自建应用，开通机器人能力。
2. 权限至少开通：获取与发送单聊、群组消息；订阅事件 `im.message.receive_v1`。
3. 应用可用范围只添加你自己。
4. 先在本机启动本程序，再在开放平台「事件与回调」中选择「使用长连接接收事件」并保存。长连接必须在线才能保存成功。
5. 手机飞书搜索该机器人，进入私聊。

启动：

```bash
python -m fundmon
```

不连飞书、只在终端看估值：

```bash
python -m fundmon preview 110022
```

## 私聊指令

| 指令 | 作用 |
| --- | --- |
| 开启 / 关闭 | 总开关。关闭后停止拉行情 |
| 分钟 15 | 每个交易时段内每 15 分钟推一次，数字可自定义 |
| 小时 1 | 每小时推一次，到点须仍在连续竞价时段 |
| 定点 10:00 14:50 | 增加固定时刻，可多条 |
| 取消分钟 / 取消小时 / 取消定点 10:00 / 取消全部 | 删除对应规则 |
| 提醒 | 查看当前开关与规则 |
| 添加 110022 | 加入自选并立刻拉取前十大持仓 |
| 删除 110022 | 移出自选 |
| 列表 | 查看自选 |
| 估值 | 立刻估算并推一张卡片，不受总开关限制 |

三类规则可同时生效。再发 `分钟 15` 会覆盖旧的分钟间隔；定点按集合增减。

## 估算方式

`估算涨跌幅 = Σ(占净值比例 × 股票涨跌幅) / 100`

其余仓位按 0 涨跌。持仓来自季报，通常滞后一到三个月，只作盘中方向参考，不会与天天基金估值数字对齐。

当前仅覆盖持仓以 A 股为主的场外基金。
